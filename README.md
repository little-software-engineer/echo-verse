# EchoVerse

EchoVerse is a cinematic ASP.NET Core MVC web application that explores music artists through immersive visual storytelling, interactive timelines, and curated inspirations.

The project focuses on blending music, film aesthetics, gaming culture, and visual eras into a polished digital experience rather than a traditional CRUD-style music database.

Currently centered around The Weeknd’s discography and artistic evolution, the platform is designed to feel like an interactive digital exhibition.

---

# Features

## Artist Exploration
- Browse artists through interactive cards
- Dynamic mood-based visual styling
- Responsive layouts with modern UI

## Album Timelines
- Scrollable era-based timeline experience
- Album progression visualization
- Era-specific cinematic themes

## Inspirations System
Albums can contain curated inspirations such as:
- Movies
- Video games
- Visual aesthetics
- Cultural references

Each inspiration helps connect the artist’s work to broader media influences.

## Live Search
- Artist search
- Album search
- Live autocomplete suggestions

## Music Integration
- Spotify embeds for selected albums/tracks
- Immersive listening experience

# Project Philosophy

EchoVerse is designed as a curated experience rather than a user-generated platform.

The goal is to create an emotionally immersive interface where music eras feel like cinematic worlds users can explore.

Inspired by:
- Synthwave aesthetics
- Modern music storytelling
- Interactive media archives
